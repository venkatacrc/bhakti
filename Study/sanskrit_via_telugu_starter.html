1. Learning Roadmap

Goal: move from “I can chant with Telugu script support” → “I can parse a verse into stems, cases, and compounds” → “I can read Gītā and Sahasranāmam with diminishing dictionary dependence.” Times assume ~30–45 minutes/day, 5–6 days/week. Stretch or compress freely.

Phase 0 — Script bridge & listening (2–3 weeks)

Outcome: comfortable reading Telugu-script Sanskrit side-by-side with Devanagari; ear trained to chant cadence.

  • Use any page’s two-column layout: Devanagari left, Telugu right (e.g. Ganesha Pancharatnam).
  • Map Devanagari ↔ Telugu letter-by-letter for 10–15 minutes/day (vowels, conjuncts, anusvāra, visarga).
  • Listen + follow along: Hanuman Chalisa / Suprabhatam YouTube links on the index.
  • Do not chase full grammar yet — chant accuracy and script fluency first.
↑ Contents

Phase 1 — Grammar foundations (4–6 weeks)

Outcome: recognize sandhi seams, name the seven vibhaktis, spot common samāsas, conjugate a few high-frequency roots.

  • Work through §2 Grammar Primer in this document — one subsection per week.
  • Drill §3 Cognate Glossary in small batches (10–15 words/day); say the Telugu tatsama aloud.
  • Pick 2–3 lines from a short stotra and mark: sandhi cuts, vibhakti endings, compounds.
  • Primary practice text: Ganesha Pancharatnam (5 verses, dense compounds).
↑ Contents

Phase 2 — Short stotras (6–8 weeks)

Outcome: parse a full short stotra with word-meanings, then without looking at English for known words.

  • Liṅgāṣṭakam — regular aṣṭaka pattern, clear refrain.
  • Bhavānī Aṣṭakam — repeated “tvām… śaraṇaṃ” frame.
  • Gurvaṣṭakam — philosophical vocabulary that will return in Gītā.
  • Saṅkaṭa Mochana Hanumān Aṣṭakam — narrative verbs + vocatives.
  • Optional parallel Awadhi/Hindi bridge: Hanumān Cālīsā (not Classical Sanskrit — useful for devotion + cognates only).
↑ Contents

Phase 3 — Longer stotras (8–12 weeks)

Outcome: sustain attention across longer anuṣṭubh / complex metres; track recurring name-epithet compounds.

  • Bhaja Govindam — ideal “grammar meets meaning” text; short lines, sharp vocabulary.
  • Kanakadhārā Stotram — dense feminine imagery, long compounds.
  • Dakṣiṇāmūrti Stotram — Advaita technical terms.
  • Mahiṣāsura Mardinī — fast chant; focus on name-lists + alliteration, not every rare word.
  • Śrī Veṅkaṭeśwara Suprabhātam — morning liturgy vocabulary; good for listening practice.
  • Guru Pādukā Stotram — bhakti + guru-śiṣya lexicon.
↑ Contents

Phase 4 — Bhagavad Gītā (4–8 months)

Outcome: read a chapter verse-by-verse with sandhi split; follow argument arcs, not only isolated ślokas.

  • Start with Ch. 12 (Bhakti Yoga) — shortest, clearest devotion chapter — then Ch. 2, then sequential 1–18.
  • All 18 chapters are in BhagavadGita/ with Telugu script + light hyphenation for reading.
  • Pace: ~1 chapter/week for short ones; 2–3 weeks for Ch. 2, 11, 18.
  • Weekly drill: pick 5 verses; strip sandhi; label vibhakti; paraphrase in Telugu from cognates before reading English meaning.
↑ Contents

Phase 5 — Viṣṇu Sahasranāmam (ongoing / 3–6+ months)

Outcome: treat the thousand names as a vocabulary + compound gymnasium; chant with comprehension of name clusters.

  • Text: Viṣṇu Sahasranāmam.
  • Method: 10–25 names/day — derive from roots/cognates; note recurring prefixes (vi-, su-, a-, nir-, mahā-).
  • Do this alongside Gītā, not only after — names reinforce Gītā theology vocabulary.

2. Grammar Primer (తెలుగు దృష్టితో)

తెలుగు మాట్లాడేవారికి సంస్కృతం కొత్త భాష కాదు — ఇది తత్సమ / తద్భవ పదాల ద్వారా ఇప్పటికే మీ నోట్లో ఉన్న భాష. క్రింది విభాగాలు తెలుగు వ్యాకరణ పదజాలంతో సంస్కృత మూలాలను కలుపుతాయి.

2.1 సంధి (Sandhi) — అక్షరాల కలయిక

తెలుగులో కూడా మాటలు కలిస్తే ధ్వని మారుతుంది (ఉదా: రాముడు + అయ్యా → రాముడయ్యా). సంస్కృతంలో ఇది నియమబద్ధం — శ్లోకంలో రెండు పదాలు అంటుకుని కనిపిస్తాయి. చదవడానికి ముందు సంధి విడదీయండి.

స్వరసంధి (vowel sandhi) — ముఖ్యమైనవి

నియమంఉదాహరణతెలుగు గుర్తు
అ/ఆ + అ/ఆ → ఆ राम + अयम् → रामायम् (సాధారణ నమూనా: हित + अर्थ → हितार्थ) హితార్థం లాంటి తత్సమాల్లో ఇదే జరుగుతుంది
అ/ఆ + ఇ/ఈ → ఏ देव + इन्द्र → देवेन्द्र దేవేంద్ర
అ/ఆ + ఉ/ఊ → ఓ गङ्गा + उदक → गङ्गोदक నది + నీరు కలయిక — సుప్రభాతం / స్తోత్రాల్లో సాధారణం
ఇ + ఇ → ఈ; ఉ + ఉ → ఊ अति + इव → अतीव అతీవ (భజ గోవిందం: अतीव विचित्रः)
అ/ఆ + ఋ → అర్ महा + ऋषि → महर्षि మహర్షి
ఏ/ఓ + అ → అయ్/అవ్ (ప్రకృతి భేదం) वने + अपि → वनयपि / वनऽपि (లిపిలో అవగ్రహం ऽ) గీతలో कोऽपि = कः + अपि

వ్యంజన / విసర్గ సంధి — చదవేటప్పుడు గుర్తుంచుకోండి

నియమంఉదాహరణగమనిక
త్ + చ్ → చ్చ్ तत् + च → तच्च గీత/స్తోత్రాల్లో तच्च, यच्च
న్ + ల్ → ల్ల్ / ం ల్ तम् + लोकम् వంటి సందర్భాలు చదువుతూ నాసిక్యం వినండి
విసర్గ (:) + అఘోష → ఓ / అః మార్పు रामः + गच्छति → रामो गच्छति పురుషవాచక ప్రథమా ఏకవచనం చాలా సార్లు -ोగా కనిపిస్తుంది
విసర్గ + చ్/ఛ్ → శ్ नमः + शिवाय → नमश्शिवाय / नमः शिवाय జపంలో సాధారణం

అభ్యాసం: Bhaja Govindam లోని ఒక శ్లోకం తీసుకుని, ఆంగ్ల word-meaning చూసే ముందు సంధి విడదీసి రాయండి.

2.2 సమాసం (Samāsa) — పదాల కూర్పు

తెలుగులోనూ సమాసాలున్నాయి (గృహప్రవేశం, రాజమార్గం, నీలకంఠుడు). సంస్కృత స్తోత్రాలు సమాసాల మీదే నడుస్తాయి — ముఖ్యంగా Gaṇeśa Pañcaratnam, Kanakadhārā.

రకంసంస్కృత పేరుఅర్థ సూత్రంఉదాహరణ + తెలుగు
తత్పురుష तत्पुरुष రెండవ పదం ప్రధానం; మొదటిది విశేషణం/సంబంధం राजपुरुषः = రాజుయొక్క పురుషుడు → రాజపురుషుడు
కర్మధారయ कर्मधारय ఒకే వస్తువుకు రెండు పేర్లు / విశేషణం+నామం नीलम् + उत्पलम् → नीलोत्पलम् → నీలోత్పలం
ద్వంద్వ द्वन्द्व A మరియు B — రెండూ సమానం रामलक्ष्मणौ → రామలక్ష్మణులు
బహువ్రీహి बहुव्रीहि “ఎవరికి/దేనికి అది ఉందో” — బయటి వ్యక్తిని సూచిస్తుంది पीताम्बरः = పీత వస్త్రం ఉన్నవాడు (విష్ణువు) → పీతాంబరుడు
ద్విగు द्विगु సంఖ్య ముందు त्रिलोकम् → త్రిలోకం; पञ्चरत्नम् → పంచరత్నం
అవ్యయీభావ अव्ययीभाव అవ్యయం + నామం = క్రియా విశేషణం లాంటి ఏకపదం यथाशक्ति → యథాశక్తి; आजन्म → ఆజన్మ

ఉదా (Pañcaratnam): विलासिलोकरक्षकम् = विलासि-लोक-रक्षकम् (కర్మధారయ / తత్పురుష గొలుసు) — “విలాస లోకాన్ని రక్షించేవాడు.”

2.3 విభక్తి (Case) — కారకాలు

తెలుగులో విభక్తి ప్రత్యయాలు స్పష్టం: -డు/-ము, -ని, -చేత, -కు, -నుంచి, -యొక్క, -లో, -తో. సంస్కృతంలో అవే అర్థాలు ప్రత్యయాల రూపంలో నామవాచకం చివర కలుస్తాయి. ఏకవచనం (singular) అజంత పుంలింగ राम నమూనా:

#విభక్తిసంస్కృత రూపంతెలుగు సమానంప్రశ్న
1ప్రథమా (Nominative)रामःరాముడు (కర్త)ఎవరు?
2ద్వితీయా (Accusative)रामम्రాముని (కర్మ)ఎవరిని?
3తృతీయా (Instrumental)रामेणరాముని చేత / తోఎవరితో? దేనితో?
4చతుర్థీ (Dative)रामायరామునికిఎవరికి?
5పంచమీ (Ablative)रामात्రాముని నుండిఎక్కడ నుండి?
6షష్ఠీ (Genitive)रामस्यరాముని యొక్కఎవరిది?
7సప్తమీ (Locative)रामेరామునిలో / వద్దఎక్కడ?
—సంబోధన (Vocative)हे रामఓ రామా!పిలుపు

స్త్రీలింగ నమూనా (लता): लता, लताम्, लतया, लतायै, लतायाः, लतायाः, लतायाम् — తెలుగు తత్సమాల్లో భక్తి, శక్తి, ముక్తి వంటి -ि నామాలు గీతలో ఎక్కువ.

భజ గోవిందం: का ते कान्ता कस्ते पुत्रः — का (ప్రథమా), ते (షష్ఠీ/చతుర్థీ “నీ”), कान्ता (ప్రథమా), कः + ते, पुत्रः.

2.4 ధాతు (Verb roots) — ప్రాథమిక conjugation

సంస్కృత క్రియ = ధాతు + లకారం (కాలం/మూడ్) + పురుష/వచన ప్రత్యయం. తెలుగు క్రియల్లోనూ మూలం కనిపిస్తుంది: గమనం ← గమ్, దర్శనం ← దృశ్, స్మరణం ← స్మృ.

లకారాలు మీకు ముందుగా కావాల్సినవి

లకారంఉపయోగంఉదా (भू “to be”)
లట్ (వర్తమాన)జరుగుతోందిभवति — అగును / ఉంటాడు
లోట్ (విధి/ఆదేశ)చేయి! / అవ్వాలిभवतु — అవునుగాక
లఙ్ (భూత)గతంअभवत् — అయ్యెను
లృట్ (భవిష్యత్)వస్తుందిभविष्यति — అగును
విధిలిఙ్చేయవచ్చు / చేయాలి (మృదువు)भवेत् — కావచ్చు

పరస్మైపద లట్ — पठ् (చదువు) నమూనా

ఏకవచనంద్వివచనంబహువచనం
ప్రథమ పురుష (he/they) पठति पठतः पठन्ति
మధ్యమ (you) पठसि पठथः पठथ
ఉత్తమ (I/we) पठामि पठावः पठामः

స్తోత్రాల్లో తరచు కనిపించే ధాతువులు

ధాతుఅర్థంసాధారణ రూపంతెలుగు తత్సమ / తద్భవ
नम्వంగు, నమస్కరించుनमामि, नतःనమస్కారం, నతుడు
भज्సేవించు / పంచుకొనుभज, भजतिభజన, భక్తి
गम् / इపోगच्छति, एतिగమనం, ఆగమనం
कृచేయుकरोति, कुरु, कृतम्కర్త, కృతం, సంస్కారం
भू / अस्అగు / ఉండుभवति, अस्तिభవితవ్యం, అస్తిత్వం
ज्ञाతెలుసుకొనుजानाति, ज्ञात्वाజ్ఞానం, విజ్ఞానం
दृश्చూచుपश्यति, दृष्ट्वाదర్శనం, దృష్టి
पा / रक्ष्కాపాడుपाति, रक्षतिపాలన, రక్షణ
मुच्విడుదలमुञ्चति, मुक्तःముక్తి, విముక్తి
स्मृగుర్తుంచుस्मरति, स्मृत्वाస్మరణ, స్మృతి

క్త్వా / ల్యప్ (తెలుగు “-ి” / “చేసి”): दृष्ट्वा = చూసి; ज्ञात्वा = తెలుసుకొని; हित्वा = విడిచి — భజ గోవిందం / గీతలో అతి సాధారణం.

4. Study Method (with this repo)

Four-step loop for any verse page — use it so you never need to re-copy stotra text into notes.

  1. Chant — Telugu column first if Devanagari is slow; then match Devanagari.
  2. Cut — write the line with sandhi split (pencil or digital note). Mark vibhakti endings in a second color.
  3. Bridge — circle every cognate you know from §3; guess the rest before opening the page’s English word-meaning.
  4. Confirm — read Words then Meaning on the HTML page; add 3–5 new items to your personal glossary.
